# 轻量格式卡片预览设计

## 背景

当前卡片预览为纯文本，字号偏小，且会移除所有 Markdown 格式，导致可读性不足。

## 目标

- 预览支持轻量格式：标题、列表、引用、粗体、斜体、行内代码。
- 仅提取前 200 个可见字符（而不是整篇笔记）。
- 保持现有虚拟列表与按可视区 hydration 的性能特征。

## 已确认规则

- 采用方案 A：单次线性扫描 + 轻量块级解析。
- 若开头是代码块：显示前几行代码（固定 4 行）。
- 若开头是图片：跳过图片，从图片后正文开始渲染。
- 若单篇笔记不足 200 可见字符：完整显示，不补齐，不加省略号。
- 仅当超过 200 可见字符时，才截断并追加 `...`。

## 解析与渲染策略

1. 预处理
   - 去除 frontmatter。
   - 统一换行符。

2. 起始区处理
   - 跳过空行与纯图片行。
   - 若首个有效块是围栏代码块，进入代码预览分支。
   - 否则进入正文轻量解析。

3. 代码预览分支
   - 提取围栏内前 4 行。
   - 受 200 可见字符预算约束。
   - 超限或被截断时追加 `...`。

4. 正文轻量解析分支
   - 块级：标题、列表、引用、段落。
   - 行内：粗体、斜体、行内代码。
   - 链接保留可读文本，移除 URL。
   - 图片语法移除，不计入字符预算。

5. 安全策略
   - 预览 HTML 仅由受控标签生成。
   - 对文本内容统一 HTML 转义，避免注入风险。

## 数据结构调整

在 `NoteCardRecord` 新增：

- `previewHtml: string`
- `previewMode: "text" | "code" | "empty"`

## UI 调整

- 卡片预览区域改为渲染轻量 HTML。
- 增大预览字号与行高。
- 为代码预览提供独立样式（等宽字体、背景、边框）。
- 通过限制预览区域高度，保持虚拟列表的固定高度假设。

## 验收标准

- 预览可显示轻量格式，不再是纯文本。
- 开头代码块按规则展示前 4 行代码。
- 开头图片可跳过并继续渲染正文。
- `< 200` 可见字符时完整显示、无省略号。
- `> 200` 可见字符时截断并追加省略号。
- `npm run check` 与 `npm run build` 均通过。
