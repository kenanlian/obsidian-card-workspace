# Navigation visibility / 导航隐藏

Right-click a folder or tag and choose **Hide this folder / tag** to hide its entire navigation subtree. The vault root stays available as an individual entry; hide the **Folders** section to hide it. Right-click any of the six section headings and choose **Hide this section**.

Open **Settings → Card Workspace → Navigation** to toggle Favorites, Folders, Tags, Properties, Card boxes, and Links. You can hide all six; the navigation pane then shows a reminder to restore them from settings. Section order, collapse, and expansion are retained. Moving a section skips hidden sections and leaves their positions unchanged.

Use **Manage** beside Hidden folders or Hidden tags to search a snapshot of the whole vault, including parent tags inferred from nested tags. A checked entry is hidden. Child entries hidden by a parent show the reason and cannot be edited until you restore the parent. If a child was also hidden independently, restoring the parent keeps that child hidden. Use Hide / Restore matching entries for batch changes, or Restore all to clear the draft. **Done** saves; **Cancel** discards the draft. If saving fails, the draft stays open with an error; click Done again to retry.

Hidden rules are shared by every view and saved across restarts. Missing entries stay in the manager until manually restored. Folder renames and moves update the rules. Renaming tags through the plugin updates their rules; if only some notes are renamed, both old and new rules remain. External tag renames do not infer a mapping.

Hiding changes navigation display only. Your current card stream, search results, tag and property filters, note counts, and existing favorites keep working. Navigation search and automatic reveal cannot show a hidden item.

右键文件夹或标签，选择**隐藏此文件夹／标签**即可隐藏整个导航子树。仓库根目录不提供单项隐藏，可通过隐藏**文件夹**分区处理。六个分区标题的右键菜单均提供**隐藏此分区**。

在**设置 → Card Workspace → 导航**中可切换收藏、文件夹、标签、属性、卡片盒和链接的显示。允许隐藏全部分区，导航空态会提示从插件设置恢复。恢复保留分区排序、折叠及展开状态；分区上移／下移会跳过隐藏分区，隐藏分区的位置不变。

点击隐藏文件夹或隐藏标签旁的**管理**，可搜索每次打开时收集的全库列表，标签列表包含嵌套标签的合成父标签。勾选表示隐藏。因父项隐藏的子项会显示原因，需先恢复父项才能单独操作；原本独立隐藏的子项在恢复父项后仍隐藏。可批量隐藏／恢复匹配项，或全部恢复草稿中的条目。**完成**保存，**取消**放弃；保存失败时保留草稿并显示错误，再次点击完成即可重试。

规则在所有视图间共享并跨重启保留。当前未找到的条目仍在管理列表中，直到手动恢复。文件夹重命名或移动会同步更新规则；通过插件重命名标签也会同步，部分成功时保留旧规则并添加新规则。外部标签改名不会猜测映射。

隐藏仅影响导航展示。当前卡片流、搜索结果、标签与属性筛选、笔记计数和已有收藏仍可使用。导航搜索和自动定位均不能显示隐藏条目。
